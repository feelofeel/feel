# FEEL Foundation

The conceptual base of FEEL as a standalone product: what it promises, why it should work, what the evidence says, and how the promise gets tested. Everything here is **rigor-side** — conservative, falsifiable, free of brand voice. Brand voice lives in [`../brand/`](../brand/lore.md) and never leaks into this folder.

| Doc | What it holds |
|---|---|
| [promise.md](promise.md) | The value claims, stated falsifiably, each with its current evidence status |
| [principles.md](principles.md) | First principles — why the mechanism works, one idea per line |
| [evidence.md](evidence.md) | Append-only ledger of measured facts; case studies and bench results land here |
| [bench-protocol.md](bench-protocol.md) | **eelbench** — the pre-registered FEEL / no-FEEL experiment design |

Conventions for this folder: docs carry FEEL heads but **no `app_version`** (FEEL has no release train yet; `doc_revision` + `updated` carry versioning). Claims stronger than the evidence ledger supports don't ship — when in doubt, downgrade the claim, not the honesty.
